## Main Features



* **Running Process Collection**

  Collects information about active processes, including process IDs, users, resource usage, parent processes, start times, and executed commands.



* **Logged-In User Detection**

  Records users currently connected to the system, their terminal sessions, login times, source addresses, and current activity.



* **Network Connection Collection**

  Captures active TCP and UDP connections, local and remote addresses, connection states, ports, and associated processes.



* **Listening Port Detection**

  Identifies services waiting for incoming connections and records their listening addresses, ports, and owning processes.



* **Recent Command History Collection**

  Collects recent commands from supported shell history files to help identify actions performed before or during an incident.



* **System Information Collection**

  Gathers essential system details such as hostname, operating system, kernel version, architecture, uptime, network interfaces
